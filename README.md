# Rangkuman Week 1 - Version Control (Git)

## Version Control
Sistem yang dapat mengelola perubahan terhadap kode atau dokumen yang memungkinkan tim atau individu melacak setiap versi dari perubahan yang dibuat.

## Git dan Github
Git merupakan salah satu version control yang memungkinkan developer mengelola perubahan kode, baik secara individu maupun kolaboratif. Github adalah platform web yang menggunakan Git sebagai basisnya, yang memfasilitasi kolaborasi tim dalam mengelola dan membagikan kode.

## Fitur Penting Git
- Commit: Menyimpan perubahan dari kode pada waktu tertentu
- Branching: Membuat cabang kode
- Merging: Menggabungkan perubahan dari branch berbeda ke branch utama
- Revert: Mengembalikan perubahan
- Stash: Menyimpan perubahan sementara tanpa commit

## Alur Kerja
- Centralized workflow: Semua developer bekerja pada satu branch
- Feature branch workflow: Setiap fitur memiliki branch sendiri
- Gitflow: Memiliki branch khusus untuk pengembangan, pengujian, dan produksi

## Perintah dasar Git:
- git init: Menginisialisasi repositori baru
- git status: Memeriksa perubahan yang terjadi
- git add: Menambahkan perubahan ke staging area
- git commit: Menyimpan perubahan sebagai satu versi
- git push: Mengunggah perubahan ke repositori jarak jauh
- git pull: Mengambil pembaruan dari repositori jarak jauh
- git reset: Mengembalikan ke commit tertentu
